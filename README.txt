CRÉDITOS LA ABUELITA V1.3

1. En Supabase SQL Editor, ejecutar INSTALAR_V1_3.sql una vez.
2. Subir index.html, app.js, style.css y los demás archivos web a la raíz de GitHub Pages (NO subir los .sql al sitio público).
3. Actualizar la página o reiniciar la PWA.
4. Administrador > Configuración: activar/desactivar búsqueda e historial general para operadores. Guardar.
5. El operador verá los cambios al actualizar la página o navegar entre secciones; el botón Ver sigue funcionando.

La instalación no elimina datos. El historial se oculta en el menú del operador, pero Ver por cliente conserva sus movimientos. Esto es una restricción de interfaz, no una prohibición de acceso a movimientos desde la base de datos.

Requiere V1.2 ya instalada en Supabase.
